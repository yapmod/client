---
title: Themes
description: Install, enable, and manage CSS themes in Yapin.
---

Themes change how Yapin looks by adding CSS on top of the page. Yapmod can install a theme
from a CSS file you already have, or from a direct link to a CSS file hosted online. Themes
are stored in this browser and applied automatically whenever Yapmod is loaded.

You will find the theme manager under **Yapin settings → Yapmod → Themes**.

## What is on the page

- A search field that filters local themes by name, author, and description, and online
  themes by title, URL, and light/dark mode.
- **Add Theme**, which opens the add form.
- A safety card with the theme warning and links to places where themes are shared.
- One card per installed theme, sorted by name. Local and online themes share the same
  list.

Each card has an enable switch and a delete button. Local cards also show the theme's
author, version, description, and any website or Discord invite links declared by the theme.
Online cards show the URL and whether the theme applies always or only in light or dark
mode.

## Install a local theme

Use this when you have a `.css` or `.theme.css` file, or want to paste CSS directly.

1. Open **Yapmod → Themes** and select **Add Theme**.
2. Leave **Online theme** turned off.
3. Upload the file with **Upload CSS**, or paste its contents into the **CSS** field.
4. Check the **Name**, **Author**, and **Description** fields. Yapmod fills them from the
   theme's metadata header when they are blank; anything you type overrides the header.
5. Select **Add Theme**.

A newly added local theme starts **disabled**. Turn on its switch to apply it.

### Theme metadata

Yapmod reads the first `/** ... */` comment block in the CSS file. This header format is
widely used by CSS themes:

```css
/**
 * @name Midnight
 * @author you
 * @description A dark blue theme for Yapin.
 * @version 1.0.0
 * @website https://example.com/midnight
 * @invite your-invite-code
 */

:root {
  --accent: #7aa2f7;
}
```

| Field          | Used for                                                                           |
| -------------- | ---------------------------------------------------------------------------------- |
| `@name`        | The card title. Falls back to the file name.                                       |
| `@author`      | The author line. Falls back to "Unknown Author".                                   |
| `@description` | The card description. Falls back to "A Yapin theme."                               |
| `@version`     | An optional version label on the card.                                             |
| `@website`     | An optional **Website** link. Must be an `http(s)` URL.                            |
| `@invite`      | An optional **Discord Server** link. Accepts an invite code or a `discord.gg` URL. |

The metadata comment stays part of the CSS; it is a comment, so it has no effect on the
page.

### Replacing a theme

The uploaded file name is the theme's identity. Uploading a file with the same name
replaces the existing theme and keeps its enabled state, which makes updates painless.
Renaming the file installs it as a separate theme. Themes pasted without a file use a file
name derived from their title.

## Install an online theme

Use this when the theme is published as a direct CSS link.

1. Open **Add Theme** and turn on **Online theme**.
2. Enter the **CSS URL**. It must point directly at a CSS file, not at a page that contains
   one.
3. Choose what the theme applies to:
   - **Always** applies it regardless of Yapin's current look.
   - **Light theme** applies it only while Yapin is using its light look.
   - **Dark theme** applies it only while Yapin is using its dark look.
4. Select **Add Theme**.

Online themes are enabled as soon as they are added. Yapmod resolves the light/dark choice
against Yapin's current theme and re-resolves it whenever Yapin switches between light and
dark.

Online themes are fetched and inlined rather than loaded with an external stylesheet
link. Yapin enforces a `style-src` that blocks outside CSS files, but its `connect-src`
allows a limited set of hosts. `raw.githubusercontent.com` is the practical choice for
files stored in a GitHub repository; other hosts may be blocked. If the fetch fails, the
theme card remains installed and Yapmod retries the URL after a minute.

## Enable, disable, and remove

- Use a card's switch to enable or disable that theme. Disabling a theme removes its CSS
  immediately; the theme stays installed.
- Use the delete button to remove a theme. Yapmod asks for confirmation first. Deleting a
  theme also removes it from the enabled list.
- Disabled themes are remembered as disabled. They do not re-enable themselves on reload.

## How themes are applied

Yapmod owns a single `<style>` element and rebuilds it from your enabled themes:

1. Enabled online themes are fetched through Yapin's `connect-src` allowlist, cached for
   the page lifetime, and inlined first.
2. Enabled local themes follow as plain CSS, in the order they were added, so they can
   override an online theme.
3. The stylesheet is rebuilt when you enable, disable, add, or delete a theme, when an
   online theme finishes loading, and when Yapin changes its light/dark look.

If no theme is enabled, the `<style>` element is removed entirely. Unloading Yapmod removes
it too.

## Safety

Themes are trusted CSS, not sandboxed content. A theme can restyle or hide parts of Yapin,
and a heavy theme can make the page feel slow. Only install themes from authors you trust,
and disable a theme first if Yapin starts behaving strangely.

A theme only affects the elements its selectors match. Themes written for another app, such
as Discord, may need their selectors adjusted for Yapin's markup before they do anything
useful.

## Troubleshooting

| Problem                                      | What to check                                                                                                   |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| A local theme does nothing                   | Make sure its switch is on and the CSS targets Yapin's elements.                                                |
| An online theme does nothing                 | Confirm the URL points directly at a CSS file and that its host is allowed by Yapin's CSP.                      |
| A light/dark theme applies at the wrong time | Check the theme's **Apply to** setting against Yapin's current look.                                            |
| Two themes fight each other                  | Disable one. Later rules and `!important` declarations win, so combining themes can produce unexpected results. |
| Yapin looks broken                           | Disable or delete the most recent theme, then reload the page.                                                  |

Themes are stored in `localStorage` under `yapmod.themes.v1`. See
[Installing Yapmod](/docs/guide/installing#where-your-data-lives) for what that means for
backups and clearing site data.
