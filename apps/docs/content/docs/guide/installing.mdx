---
title: Installing Yapmod
description: Load the client into Yapin, verify it is running, and unload it again.
---

Yapmod is not an extension or a separate application. It is a JavaScript bundle that you
load into an already open Yapin page. This page covers loading it, checking that it works,
and removing it.

## What you need

- Yapin open in a desktop browser.
- The built client bundle, `yapmod-client.js`. If you are building it yourself, run
  `pnpm build` in the repository; see [Development Setup](/docs/development).
- Access to the browser's developer console, or a way to load the file into the page.

## Load the client

The bundle is a classic script that starts itself as soon as it is evaluated. There are
two practical ways to load it:

1. **Paste it into the console.** Open Yapin, open the developer tools, paste the entire
   contents of `yapmod-client.js` into the console, and run it. This is the simplest way to
   try a build.
2. **Load it with a script tag.** Serve the file and add a classic script tag that points
   at it. Yapin's Content-Security-Policy may restrict which hosts scripts can be loaded
   from, so the console path is the most reliable one.

Loading the bundle twice is safe. If Yapmod is already running, the second load returns the
existing instance instead of starting a second copy.

## Check that it is running

The bundle exposes a small handle on `globalThis.YapmodClient`. In the console, check its
state:

```js
YapmodClient.state; // "ready"
YapmodClient.version; // the loaded build's version
```

Then open Yapin's settings. A new **Yapmod** group appears in the settings navigation with
three entries:

| Entry        | What it contains                                                                 |
| ------------ | -------------------------------------------------------------------------------- |
| **Settings** | The installed version, the bundle name, and an **Unload** button.                |
| **Plugins**  | Install, enable, update, and remove plugins. See [Plugins](/docs/guide/plugins). |
| **Themes**   | Install, enable, and remove CSS themes. See [Themes](/docs/guide/themes).        |

## Unload the client

Use **Settings → Yapmod → Settings → Unload**, or call `YapmodClient.dispose()` in the
console. Unloading removes every element and stylesheet Yapmod injected, stops running
plugins, and closes its dialogs. It does not delete your saved themes or plugins; those
stay in this browser and are available the next time you load the client.

Reloading the Yapin page has the same effect as unloading, because the bundle only exists
for the lifetime of the page. After a reload, inject the script again to bring Yapmod back.

## Updating

Replace the injected copy with a newer build: reload Yapin, then load the new
`yapmod-client.js`. Saved themes and plugins are kept across updates because they live in
the browser's `localStorage`, not in the bundle.

## Where your data lives

Themes and plugins are stored per browser and per Yapin origin. They are not synced between
browsers, profiles, or devices. Clearing the site's data removes them, so keep a copy of any
local theme or plugin file you want to reinstall.

| Data                | Storage key              |
| ------------------- | ------------------------ |
| Themes              | `yapmod.themes.v1`       |
| Installed plugins   | `yapmod.plugins.v1`      |
| Per-plugin settings | `yapmod.plugins.data.v1` |
