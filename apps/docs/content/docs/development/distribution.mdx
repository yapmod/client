## Publish your catalog

The [Plugin Starter](/docs/setup/starter-repo) includes a GitHub Actions workflow for distribution. Each public repository publishes its own catalog. Its maintainer chooses which plugins appear there.

1. In your public repository, enable GitHub Actions. In **Settings → Pages**, choose **GitHub Actions** as the publishing source.
2. Push your plugins to the default branch. You can also select that branch under **Actions → Plugin catalog → Run workflow**.
3. Once the workflow succeeds, open the deployment URL in its summary. Share this page with users who want to browse or download your plugins.

The workflow type-checks and builds the collection before publishing. It deploys the catalog to Pages and writes the generated files to the `plugin-dist` branch using the repository’s built-in token. Allow the workflow to write to that branch. Each push to the default branch refreshes both destinations.

## Install a plugin by URL

1. On the author’s catalog page, copy the **Yapmod import URL** for the plugin you want.
2. In Yapmod settings, open **Plugins → Add Plugin** and leave **Local plugin** off.
3. Paste the link into **Plugin URL** and select **Fetch**.

The import URL points to a public GitHub Raw folder such as `https://raw.githubusercontent.com/OWNER/REPO/plugin-dist/weather/`. Yapmod fetches `plugin.json` for metadata and `plugin.js` for the code. Share this URL for a specific plugin, or share the Pages URL for the whole collection.

## Install a download

Choose **Download JavaScript** in the catalog. In **Plugins → Add Plugin**, turn on **Local plugin**, choose **Upload JS**, enter the plugin details and select **Add**.

## Security considerations

<Callout type="error">
  Only install plugins you trust. Since there is no review process, any plugin can do anything that
  browser JavaScript can do. Always read the source code before installing a plugin from an unknown
  source.
</Callout>

Plugins run in the same context as the Yapin page. This means they have access to the DOM, localStorage, and any data visible on the page. A malicious plugin could read your messages, modify the interface in harmful ways, or exfiltrate data. Always verify the plugin's source code before installing it.
