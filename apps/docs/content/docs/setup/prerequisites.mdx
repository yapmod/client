Before we start building, you need a few tools on your machine. Let me walk you through installing each one.

## Node.js

Yapmod plugin development requires **Node.js 22** or later. If you do not have it yet, here are the best ways to install it:

- **[nvm](https://github.com/nvm-sh/nvm)** (Node Version Manager). This is the recommended approach because it makes switching between Node versions effortless.
- **[fnm](https://github.com/Schniz/fnm)** (Fast Node Manager). This works just like nvm but is faster.
- You can also download Node.js directly from [nodejs.org](https://nodejs.org/).

Once installed, check that everything is working:

```bash
node --version
# You should see v22.x.x or higher
```

If you see a version number that starts with v22 or higher, you are good to go.

## pnpm

We use **pnpm** as our package manager. It is fast and uses less disk space than other options, which is nice when you are working with multiple projects.

The easiest way to install pnpm is through npm:

```bash
npm install -g pnpm
```

You can also use [pnpm's official install script](https://pnpm.io/installation) if you prefer.

After installing, verify it works:

```bash
pnpm --version
# You should see 12.x.x or higher
```

## The Yapmod CLI

The `@yapmod/builder` package gives you the `yapmod` command line tool. This is what you will use to build and develop your plugins. Install it as a development dependency in your plugin project:

```bash
pnpm add -D @yapmod/builder
```

Once installed, you can run the `yapmod` command using `npx`:

```bash
npx yapmod --help
```

This will show you all the available commands. If you see help text, the installation worked.

To save some typing later, you can add scripts to your `package.json`:

```json
{
  "scripts": {
    "build": "yapmod build --entry src/index.ts --outfile dist/plugin.js",
    "dev": "yapmod dev --entry src/index.ts"
  }
}
```

With these scripts in place, you can simply run `pnpm build` or `pnpm dev` instead of typing out the full command every time.
