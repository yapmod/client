title: Prerequisites
description: Check the tools needed by the plugin starter before creating your project.
---

You need Node.js to run the builder, pnpm to install the project dependencies, and Git to clone the starter. You also need a desktop browser with [Yapmod loaded in Yapin](/docs/get-started) to try the result.

## Check your versions

```bash
node --version
pnpm --version
git --version
```

Use **Node.js 22 or later** and **pnpm 12**. If Node is missing, install it from [nodejs.org](https://nodejs.org/) or use a version manager such as [fnm](https://github.com/Schniz/fnm) or [nvm](https://github.com/nvm-sh/nvm). Install Git from [git-scm.com](https://git-scm.com/downloads).

With Node installed, install pnpm if needed:

```bash
npm install -g pnpm@12
```

Open a new terminal if an installed command is not found, then repeat the checks.

## Let the starter install the builder

The starter includes the Yapmod builder and TypeScript setup as project dependencies. You do not need to install the CLI globally or create a separate build configuration. Continue to [Starter repository](/docs/setup/starter-repo), where `pnpm install` installs the tools together.

For an existing standalone project, add `@yapmod/builder` as a development dependency and use `pnpm exec yapmod --help` to inspect its commands. See [Building your plugin](/docs/setup/building) for the direct CLI workflow and [Type safety](/docs/development/type-safety) for declarations.
