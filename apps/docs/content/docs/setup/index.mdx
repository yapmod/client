---
title: Set up development
description: Connect a local plugin project to Yapin and establish a working edit–save–test loop.
---

You will work in two places: a local project that builds your plugin, and a Yapin tab running Yapmod. The builder's control page connects the two for development. The client itself does not have a development server.

## 1. Prepare the tools

Install **Node.js 22 or later**, **pnpm 12**, and Git. Check them with `node --version`, `pnpm --version`, and `git --version`. The [prerequisites page](/docs/setup/prerequisites) has installation links.

## 2. Start from the plugin starter

[Fork and clone the starter](/docs/setup/starter-repo), install dependencies with `pnpm install`, then run `pnpm dev starter`. Leave that process running while you edit `plugins/starter/index.tsx`.

## 3. Connect to the app

[Load Yapmod](/docs/get-started) in Yapin. Enable **Yapmod → Settings → Enable hot reload**. Open the control page URL printed by the builder and use **Open Yapin** to establish the connection. Load Yapmod in that newly opened tab if needed. Keep the control page open.

See [Hot reloading](/docs/setup/hot-reloading) for connection details. A build completing in your terminal does not by itself mean a Yapin tab is connected.

## 4. Make a visible change

Follow [Your first plugin](/docs/development/first-plugin) to replace the starter with a character counter. Save, open a conversation, and type in the composer. Once you see the count change, the entire development loop is working.

## When you want an installable file

Run `pnpm build` in the starter. The output is `dist/<slug>/plugin.js`, where the slug is the plugin's directory name. [Building your plugin](/docs/setup/building) explains the output and manual installation. [Distribution](/docs/development/distribution) covers publishing the collection.
