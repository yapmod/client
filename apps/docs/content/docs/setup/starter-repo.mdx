The [Plugin Starter](https://github.com/yapmod/plugin-starter) lets you develop several plugins in one repository. They share the Yapmod CLI, TypeScript configuration and SolidJS typings. Each plugin has its own entry point, metadata, download and import URL.

## Start developing

Fork the starter into your GitHub account and clone your fork. From its root, run:

```bash
pnpm install
pnpm dev starter
```

Connect the control page to Yapin using the [hot reload guide](/docs/setup/hot-reloading). Then follow [Your first plugin](/docs/development/first-plugin) to replace the starter with a working character counter.

Edit `plugins/starter/index.tsx` while the dev server is running. With one plugin, you can also run `pnpm dev`.

## Add a second plugin

1. Copy `plugins/starter/` to a sibling directory such as `plugins/weather/`.
2. Edit its `package.json`. Set a distinct name and fill in the author, description and version.
3. Replace the example code in `index.tsx` and give any settings sections their own IDs.
4. Run `pnpm dev weather` to work on it. Run `pnpm build` at the root to type-check and bundle the entire collection.

The starter discovers directories under `plugins/` automatically. Use lowercase letters, digits and hyphens for the directory name. Keep it stable after publication because it forms part of the import URL.

## Writing your plugin

The entry point (`plugins/starter/index.tsx`) exports a **default function** that returns an object with lifecycle hooks. The builder supplies the plugin-scoped `yapmod` API inside your source:

```tsx
import { createSignal } from 'solid-js';

export default function () {
  return {
    onLoad() {
      yapmod.log('Plugin started!');

      yapmod.settings.registerSection({
        id: 'general',
        label: 'General',
        icon: 'settings',
        render: () => {
          const [greeting, setGreeting] = createSignal('Hello, world!');

          return (
            <yapmod.ui.SettingsPage title="My Plugin" description="Example plugin settings">
              <yapmod.ui.Section label="Appearance">
                <yapmod.ui.SettingRow label="Greeting" hint="The text shown when the plugin starts">
                  <yapmod.ui.Input value={greeting()} onChange={(v) => setGreeting(v)} />
                </yapmod.ui.SettingRow>
              </yapmod.ui.Section>
            </yapmod.ui.SettingsPage>
          );
        },
      });
    },

    onUnload() {
      yapmod.log('Plugin stopped!');
    },
  };
}
```

The `onLoad` hook runs when the plugin starts, and `onUnload` runs when it is stopped. Use these to set up and clean up your plugin resources.

## Share your plugins

The build produces a catalog at `dist/index.html` and a manifest and bundle for each plugin under `dist/<slug>/`. The starter includes a GitHub Actions workflow to publish them from your repository. Follow [Plugin Distribution](/docs/development/distribution) for the one-time Pages setup and installation steps.
