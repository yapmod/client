## What is the starter repo

The starter repository is a pre-configured project that gives you everything you need to build a Yapmod plugin. It includes:

- The **Yapmod CLI** (`@yapmod/builder`) that bundles your code into the correct format.
- A basic project structure with TypeScript and SolidJS support out of the box.
- `@yapmod/types` configured in `tsconfig.json` for full API autocompletion.
- Build scripts configured for pnpm.
- Example plugin code to help you get started.

The starter repo includes `@yapmod/types` configuration out of the box, so you get TypeScript
autocompletion for the entire plugin API immediately. See the
[Type Safety](/docs/development/type-safety) page for details on all available types.

## Why use it instead of starting from scratch

Building a Yapmod plugin requires bundling your code into a specific format that the Yapmod runtime can load. The starter repo handles all of this configuration for you, so you can focus on writing your plugin logic instead of wrestling with build tools.

With the starter repo, you can:

- Write **TypeScript** and have it compiled automatically.
- Use **JSX syntax** and **SolidJS components** in a natural way.
- Run a single CLI command to produce a ready-to-upload plugin file.

## How to set it up

Once the starter repo is available, you will clone it and install dependencies:

```bash
# Clone the starter repository
git clone https://github.com/yapmod/plugin-starter.git my-plugin
cd my-plugin

# Install dependencies
pnpm install
```

## After cloning

After cloning and installing dependencies, you can:

1. Modify the plugin source code in the `src` directory.
2. Run `yapmod build --entry src/index.ts --outfile dist/plugin.js` to compile your plugin.
3. Upload the built file to Yapmod.

For development with hot reload, run `yapmod dev --entry src/index.ts` instead.
