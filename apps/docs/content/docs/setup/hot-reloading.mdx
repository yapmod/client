Hot reloading lets you see your plugin changes in real time without manually rebuilding and re-uploading after every edit.

## How it works

The starter repo includes a development server that watches your source files for changes. When you save a file:

1. The builder recompiles your plugin.
2. The dev server sends the updated code to the Yapmod client connected to your browser.
3. Your plugin reloads instantly without refreshing the page.

## Enabling developer features

Hot reloading requires **developer features** to be enabled in Yapmod:

1. Open the Yapmod settings panel in Yapin.
2. Find the **Developer Features** option.
3. Toggle it on.

This allows Yapmod to accept connections from the development server and apply hot updates.

## Starting the dev server

From your plugin project directory, run:

```bash
pnpm dev
```

This starts the watch mode build. Keep this terminal open while you develop. Any changes you make to your plugin source will be reflected immediately in the browser.

## Using with Bun

If you are using Bun as your runtime:

```bash
bun run dev
```

## Workflow

With hot reloading enabled, your development loop becomes:

1. Edit your plugin code.
2. Save the file.
3. See the changes appear in Yapin within seconds.

No manual rebuild, no re-upload, no page refresh.
