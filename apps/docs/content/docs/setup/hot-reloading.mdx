---
title: Hot Reloading
description: See your plugin changes in real time without rebuilding or re-uploading.
---

Hot reloading lets you see your plugin changes in Yapin instantly — just save your file and the
update appears.

## Quick start

1. Enable the **Enable hot reload** toggle in the Yapmod Settings page on Yapin.
2. Run the dev server from your plugin project:

   ```bash
   yapmod dev --entry src/index.ts
   ```

3. Open the control page it prints (`http://127.0.0.1:5173`), then click **Open Yapin** to connect.
4. Keep the control page tab open. Every save is rebuilt and pushed into Yapin automatically.

### Options

| Flag       | Description                          |
| ---------- | ------------------------------------ |
| `--entry`  | Plugin entry file (required)         |
| `--port`   | Dev server port (default: 5173)      |
| `--host`   | Dev server host (default: 127.0.0.1) |
| `--minify` | Minify the bundle                    |

## How it works

The builder watches your source files and rebuilds on every save. The control page opens Yapin and
pushes each new build into it via `window.postMessage` — the only channel that survives Yapin's
Content-Security-Policy. Yapmod evaluates the new code and restarts the plugin in place, keeping
its storage intact.

A broken save never disrupts the running plugin: the new code is evaluated **before** the old one
is stopped, so a syntax error leaves the working version running.

<Callout type="info">
  A dev plugin appears with a `dev:` id prefix and a **Dev** badge. Deleting it removes the
  installed code but keeps its per-plugin storage.
</Callout>

## Workflow

Your development loop becomes:

1. Edit your plugin code.
2. Save the file.
3. See the changes appear in Yapin.

No manual rebuild, no re-upload, no page refresh.
