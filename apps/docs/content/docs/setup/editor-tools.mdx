While you can write Yapmod plugins with any text editor, certain extensions make the development experience much smoother.

## ESLint

ESLint helps catch errors and enforce consistent code style before you even run the build.

The starter repo includes an ESLint configuration out of the box. Install the ESLint extension for your editor:

- **VS Code:** [ESLint extension](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)
- **WebStorm / IntelliJ:** ESLint is built in, no extra setup needed.

## TypeScript support

TypeScript provides type checking and autocompletion for the Yapmod plugin API. Make sure your editor has TypeScript language support enabled:

- **VS Code:** TypeScript support is built in.
- **WebStorm / IntelliJ:** TypeScript support is built in.

## Prettier

For consistent code formatting, use Prettier with the following settings:

- 2-space indentation
- Single quotes
- Semicolons
- Trailing commas
- Print width of 100

The starter repo includes a Prettier configuration file, so your editor will pick up the settings automatically.

## SolidJS extensions

Since you can use SolidJS in your plugins, installing a SolidJS extension helps with JSX syntax highlighting and autocompletion:

- **VS Code:** [SolidJS extensions](https://marketplace.visualstudio.com/items?itemName=antfu.vscode-solid)

## Summary

These tools are optional but highly recommended. The starter repo is configured to work with them out of the box, so installing the extensions is usually all you need.
