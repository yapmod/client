title: Building Your Plugin
description: Compile and bundle your plugin code into a file ready for Yapmod.
---

Once you have written your plugin code, the next step is building it. Building takes all your TypeScript files, compiles them, and bundles everything into a single JavaScript file that Yapmod can load.

## The build command

In the starter repository, run `pnpm build` to type-check all plugins and generate the catalog. Each plugin’s bundle is written to `dist/<slug>/plugin.js`.

For a standalone project, invoke the builder directly:

```bash
yapmod build --entry src/index.ts --outfile dist/plugin.js
```

Let me break down what happens when you run this command:

1. The builder reads your TypeScript source files starting from the entry point you specified
2. It compiles any JSX syntax and SolidJS components into plain JavaScript
3. It bundles everything into a single file
4. It writes the final output to the path you specified

<Callout type="info">
  The starter runs TypeScript checking before bundling. When calling the CLI directly, run `tsc
  --noEmit` separately to check your types.
</Callout>

## Command options

Here are the flags you can use with the build command:

| Flag        | Description                                   |
| ----------- | --------------------------------------------- |
| `--entry`   | Your plugin entry file (required)             |
| `--outfile` | Where the built file will be saved (required) |
| `--minify`  | Minify the output bundle to reduce file size  |

The `--entry` flag tells the builder where your plugin starts, and `--outfile` tells it where to save the result. Both are required. The `--minify` flag is optional and will compress the output for smaller file size.

## Loading your plugin into Yapmod

Once the build succeeds, you will have a `.js` file ready to load. Here is how to get it running:

1. Open Yapin in your browser with Yapmod installed
2. Open the Yapmod settings panel
3. Go to the plugins section
4. Upload the built file from your `dist` folder

Yapmod will evaluate the file and your plugin will be active immediately. You should see it appear in the list of installed plugins.

## What comes next

Building and uploading works fine, but doing it every time you make a change gets tedious quickly. The next page shows you how to set up [hot reloading](/docs/setup/hot-reloading) so your plugin updates automatically the moment you save a file.
