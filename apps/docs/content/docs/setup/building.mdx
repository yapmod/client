title: Building Your Plugin
description: Compile and bundle your plugin code into a file ready for Yapmod.
---

Once you have your plugin code written, you need to build it into a single file that Yapmod can load.

## The build command

From your plugin project directory, run:

```bash
yapmod build --entry src/index.ts --outfile dist/plugin.js
```

This command uses the Yapmod CLI to:

1. Read your TypeScript source files.
2. Perform type checking and catch type errors before bundling.
3. Compile any JSX syntax and SolidJS components.
4. Bundle everything into a single JavaScript file.
5. Write the loadable expression to the output file.

<Callout type="info">
  The builder runs TypeScript type checking during compilation. If your plugin has type errors — for
  example, using a UI component with invalid props — the build will fail with a clear error message.
  See the [Type Safety](/docs/development/type-safety) page for details on available types.
</Callout>

## Options

| Flag        | Description                  |
| ----------- | ---------------------------- |
| `--entry`   | Plugin entry file (required) |
| `--outfile` | Output file path (required)  |
| `--minify`  | Minify the bundle            |

## Loading the plugin into Yapmod

After building, you can load your plugin into Yapmod:

1. Open Yapin with Yapmod installed.
2. Go to the Yapmod settings panel.
3. Navigate to the plugins section.
4. Upload the built file.

Your plugin will be loaded and active immediately.
