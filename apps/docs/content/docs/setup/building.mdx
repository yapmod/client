Once you have your plugin code written, you need to build it into a single file that Yapmod can load.

## The build command

From your plugin project directory, run:

```bash
yapmod build --entry src/index.ts --outfile dist/plugin.js
```

This command uses the Yapmod CLI to:

1. Read your TypeScript source files.
2. Compile any JSX syntax and SolidJS components.
3. Bundle everything into a single JavaScript file.
4. Write the loadable expression to the output file.

## Options

| Flag        | Description                  |
| ----------- | ---------------------------- |
| `--entry`   | Plugin entry file (required) |
| `--outfile` | Output file path (required)  |
| `--minify`  | Minify the bundle            |

## Loading the plugin into Yapmod

After building, you can load your plugin into Yapmod:

1. Open Yapin with Yapmod installed.
2. Go to the Yapmod settings panel.
3. Navigate to the plugins section.
4. Upload the built file.

Your plugin will be loaded and active immediately.
