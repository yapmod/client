title: Get started with Yapmod
description: Load the client mod into Yapin and apply your first CSS theme.
---

Yapmod runs inside the Yapin page. Once it is running, you will find a new **Yapmod** group in Yapin’s settings. If it is already there, skip ahead to [Add a theme](#add-a-theme).

## Load the client

The release contains a single file, `yapmod-client.js`. These steps use a saved browser snippet in desktop Chrome or Edge.

1. Open the [official client release](https://github.com/yapmod/client/releases/latest). Under **Assets**, download **yapmod-client.js** and open it in a text editor.
2. Open [Yapin](https://yapin.gg) and open Developer Tools in that tab. Under **Sources → Snippets**, choose **New snippet**. The **»** menu reveals **Snippets** if the tab is hidden.
3. Name the snippet `yapmod-client.js`, copy the contents of the release file into it, and save. Run it with **⌘ Enter** on macOS or **Ctrl Enter** on Windows and Linux.
4. Open Yapin’s settings and look for **Yapmod → Themes**. You can also check `YapmodClient.state` in the console. A loaded client returns `"ready"`.

A page refresh unloads the client. Run the saved snippet again to bring it back. Yapmod remembers your themes and plugins in this browser.

## Add a theme

1. In **Yapin settings → Yapmod → Themes**, choose **Add Theme**, then **Upload CSS**.
2. Select your theme’s CSS file and confirm with **Add Theme**.
3. Enable the theme to apply it to the current page. When you edit the stylesheet, upload it again with the same filename to update the installed copy.

To unload the mod while keeping the page open, run `YapmodClient.dispose()` in the console. Your saved choices will be there the next time you load it.

## Install a plugin

In **Yapmod → Plugins → Add Plugin**, use **URL** for an author's import URL or **Local → Upload JS** for a downloaded bundle. Complete the import and enable the plugin in the installed list. An import URL points to plugin metadata and code, not to an HTML catalog page. The [distribution guide](/docs/development/distribution) explains the supported formats.

Plugins run inside your Yapin page, so choose authors you trust. Their settings remain in this browser; deleting a plugin keeps its data. Disable a plugin to stop its behavior without deleting its installation.

## Keep going

[Create a theme](/docs/themes) to personalize the palette, or [build your first plugin](/docs/development/first-plugin) to add behavior. If the settings group or a customization is missing, start with [Troubleshooting](/docs/troubleshooting).
