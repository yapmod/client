Yapmod Client is a client mod for Yapin. It runs inside the Yapin page: the final build is
a **single self-contained JavaScript file that you inject into the page**, and everything
Yapmod adds (UI, runtime behavior) lives in that page's DOM and runtime.

It does not need Tauri, a desktop application, Node.js, or a separate server to run. The
project is written in TypeScript and bundled into plain browser JavaScript.

## What it is

- A self-contained bundle that initializes itself when the script is loaded.
- A small runtime with a clear lifecycle: install features, then dispose everything they
  created.
- A theme manager for local and online CSS themes, and a plugin manager.
- A codebase structured to grow into a long-term project.

## What it is not

- A sandboxed plugin platform. Plugins are trusted JavaScript and run with full access to
  the page, so only install plugins you trust.
- A complete component library.
- Anything that runs outside the Yapin page itself.

Themes and plugins are stored per browser. See
[Installing Yapmod](/docs/guide/installing#where-your-data-lives) for the storage keys and
what clearing site data removes.
