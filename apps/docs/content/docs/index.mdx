Welcome. If you are here, you probably want to learn how to create plugins for Yapmod, and you have come to the right place.

To load the client and try a theme in Yapin, follow [Get started with Yapmod](/docs/get-started). This introduction and the developer guides below cover **building plugins**.

## What you will learn

Think of this documentation as a step by step guide that takes you from knowing nothing about Yapmod plugins to having your first one running. Here is what we will cover together:

- **How to build a plugin** and what a plugin looks like. You will learn about the plugin object, its structure, and what each property does.
- **The full API reference** so you know every tool and method available to your plugin while it runs.
- **How Yapmod works under the hood**. You will see how Yapmod injects itself into the Yapin interface, customizes the DOM, and manages the plugin runtime behind the scenes.
- **How to share your plugin** with others, since Yapmod does not have a built in marketplace.
- **How to reverse engineer Yapin** so you can inspect the website, find the right DOM elements and hooks, and understand the patterns you will work with.

## What you should already know

To get the most out of this guide, you should feel comfortable with:

- **JavaScript or TypeScript**. You do not need to be an expert, but you should understand the basics like variables, functions, and how modules work.
- **Basic DOM concepts**. Knowing what the DOM is and how elements are structured will help a lot.
- **Browser extensions or content scripts**. This is helpful to know about, but not required. We will explain things as we go.

If you have these basics down, you are ready to start. Head over to the [Setup guide](/docs/setup) to get your development environment ready, and then move on to [Plugin Development](/docs/development) where we will build your first plugin together.
