## Themes change appearance. Plugins add behavior.

Use a **theme** for colors, spacing, and other CSS changes. Use a **plugin** for actions, settings, or information that changes as you use Yapin. A character counter needs a plugin; a different accent color only needs a theme.

You choose what to install. There is no built-in marketplace. Plugins run as trusted code in the page, so install code from authors you trust. Themes and plugin data are saved locally; they do not automatically follow you to another browser or device.

## A path from idea to working plugin

Start with [the development setup](/docs/setup), then follow [Your first plugin](/docs/development/first-plugin). The tutorial explains each part as you build it. Continue with [settings and storage](/docs/development/settings-and-storage) to give the counter a saved preference, and [lifecycle and cleanup](/docs/development/how-plugins-work) to understand what happens when it is disabled or reloaded.

Already building something? The [API reference](/docs/development/plugin-api) is organized for looking up contracts and edge cases. [Choose an integration](/docs/development/choosing-an-api) helps you decide which API fits your idea before you start.
