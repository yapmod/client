---
title: Open a plugin action from a message
description: Give an action a place in Yapin’s message menu and receive the message the user selected.
date: 2026-11-21

A plugin that saves messages needs to answer a small question every time someone opens a menu. Which message did they pick? A chat can replace a row while a menu is open, and two menus opened in succession can reuse the same element.

With `yapmod.contextMenus.registerAction('message', action)`, a plugin supplies a label and an `onSelect` callback. Yapmod places the action in the menu opened by right-click or **More**. Selecting the action passes the message ID captured for that opening. If the original row disappeared or now represents another message, the callback stays idle.

For a reading-list plugin, that means **Save for later** can appear alongside the actions people already use. A visibility predicate can swap in **Remove from reading list** the next time someone opens the menu. Both entries use the same keyboard navigation and styling as the surrounding actions.

The [message context menu guide](/docs/development/context-menu-actions) includes a runnable TSX example that opens a details dialog and explains how to remove an action.
