In the first version of Yapmod, changing the way a chat looked meant installing a whole desktop application. I was maintaining windows, a system tray and an updater alongside the code that let someone apply a few lines of CSS to Yapin. A fix in one part could mean shipping all of it again.

The part I wanted to keep was the one you could see _inside Yapin_. That is where I started the rewrite.

## A home in Yapin’s settings

Open settings to change something about Yapin and you are already in the right place. My aim was to give themes and plugins a spot in that sidebar. A theme can restyle the page you already have open. A plugin can add a control next to settings you already know how to use.

That decision shaped the implementation. Yapin sometimes replaces the settings panel while you are using it. Holding on to the old panel would leave Yapmod rendering into an element that had disappeared. The client watches the settings area and attaches its entries to the replacement. A plugin author can register a section and let the client handle that detail.

## One client that a host can load

The old desktop project has been retired. The new client ships as one JavaScript file that runs in the Yapin page. A host that embeds Yapin can load that same file and register its own plugins. Those plugins get the same settings and storage tools as one you add yourself.

That leaves room to work on a desktop host separately. Here on the site, I want to document the part they would share, from applying a first theme to building a plugin with a settings page of its own.

_November 20 update._ The client has reached its first stable release. [Read what shipped in Yapmod 1.0](/blog/yapmod-v1-0-0).

## November 23 update: Yapmod on your phone

Yapmod Mobile 0.1.0 ships the same client on Android and iPhone. There’s no separate plugin to install: sign in to Yapin, then open **Settings → Yapmod → Mobile** to reload the page or turn modifications off. If you need those controls before signing in, touch the Yapin view with three fingers.

[Download Yapmod Mobile](/mobile) for the Android APK or the iPhone IPA and instructions for signing it with AltStore Classic. One limit in this first release: with your permission, Yapin can send alerts to your phone while the page is running, but not while the app is suspended or closed. The [0.1.0 release notes](/releases/mobile/v0.1.0) cover the rest.

If you’d rather use Yapmod on a computer, the [desktop app](/desktop) and [browser extension](/extension) load the client there, too.
